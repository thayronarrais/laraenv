# Historical documentation images

Historical documentation images under `docs/` and `docs/screenshots/` are retained byte-for-byte from the [previously public LaraEnv tree](https://github.com/thayronarrais/laraenv/tree/00246599c0a18b9e3073023fe2a29d29c42c1929/docs) to preserve documentation links. They illustrate older interface versions using fictional fixtures. Account or Pro indicators in these captures do not describe the current offline desktop or local feature access.

This repository does not grant trademark rights, imply endorsement or certify separate vendor permission for those depictions. The owner attestation for project artwork is recorded in the [licensing guide](licensing.md); it does not sublicense vendor marks. These historical images are not current release branding or optional-runtime license clearances.

The source export policy lists these paths explicitly. Previously excluded standalone vendor art, composites and concept mockups remain excluded. None of the preserved image hashes matches that excluded set.
