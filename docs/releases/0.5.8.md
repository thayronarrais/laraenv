# LaraEnv 0.5.8 — Windows cron process cleanup

Scheduled commands that reach LaraEnv's five-minute timeout now terminate their Windows process tree, including PHP child processes. Previously, the timeout could stop only the command shell and leave its children running. Output cleanup is also bounded so inherited output pipes cannot keep the timed-out command waiting indefinitely.

An upgrade is recommended if you use LaraEnv's Cron page. Existing cron entries and project data are preserved. This release does not automatically change saved commands: for Laravel's scheduler, configure `php artisan schedule:run` with `* * * * *`. The long-running `schedule:work` command should not be launched by a cron entry every minute.

## Downloads and upgrades

- Windows 10/11 x64 installer: `LaraEnv-0.5.8.msi`.
- Portable edition: extract `LaraEnv-0.5.8-portable-win64.zip` and run `LaraEnv.exe` beside `.laraenv-portable`.
- The separate `LaraEnv.exe` is the portable updater payload. Each download has a matching SHA-256 sidecar.

Close LaraEnv before installing. The installer supports upgrading public 0.5.7. If you installed a local validation MSI numbered 0.5.8 or higher, remove that test application before installing this release; preserve your environment folders, projects and database data.
